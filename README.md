# ALPR System (Automatic License Plate Recognition)

Система реального часу для автоматичного розпізнавання та відстеження номерних знаків транспортних засобів у відеопотоці. Проект реалізовано з урахуванням специфіки українського стандарту номерних знаків (ДСТУ 4278:2019) та адаптовано до складних умов зйомки (недостатнє освітлення, опади, поворот камери).

## Основні можливості

- **Детекція ROI:** Виділення області номерного знака за допомогою білатеральної фільтрації, детектора Кенні та контурного аналізу.
- **Препроцесинг зображення:** Корекція перспективи (Perspective Warp), кубічне збільшення (3.0x), адаптивне вирівнювання гістограми (CLAHE) та бінаризація за методом Оцу.
- **Нейромережеве OCR:** Використання EasyOCR (CRNN: CNN + LSTM + CTC) для зчитування символів.
- **Трекінг об'єктів:** Відстеження центроїдів (CentroidTracker) на основі Евклідової відстані з присвоєнням унікального `car_id`.
- **Часова стабілізація (Rolling Vote):** Накопичення спроб розпізнавання за останні 25 кадрів та вибір моди послідовності для усунення випадкових помилок.
- **Постобробка та валідація:** Перевірка структури за допомогою регулярних виразів та позиційна заміна схожих символів (омогліфів, наприклад `0` <-> `O`, `1` <-> `I`).
- **Багатопотоковий GUI:** Графічний інтерфейс на PyQt6 із винесенням обчислень у фоновий потік (`QThread`), що забезпечує чуйність UI.

## Стек технологій

- **Мова:** Python 3.11+
- **Комп'ютерний зір:** OpenCV, NumPy, SciPy
- **OCR:** EasyOCR, PyTorch
- **GUI:** PyQt6
- **Тестування:** PyTest (38 модульних тестів)

## Структура проекту

```
ALPRPipeline (Оркестратор)
├── PlateDetector        # Локалізація номерного знака
├── image_utils          # Попередня обробка кадру
├── PlateRecognizer      # Нейромережеве розпізнавання тексту
├── CentroidTracker      # Трекінг та керування ID
├── PlateValidator       # Позиційна корекція та regex-валідація
└── PyQt6 GUI            # Візуалізація та виведення логів
```

## Встановлення та запуск

1. **Клонувати репозиторій:**
```bash
   git clone https://github.com/SnizhanaDem/Coursework-ALPR.git
   cd Coursework-ALPR/alpr_system
```

2. **Налаштувати віртуальне середовище та встановити залежності:**
```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # venv\Scripts\activate   # Для Windows

   pip install -r requirements.txt
```

3. **Запустити програму:**
```bash
   python main.py
```

## Тестування

Для запуску модульних тестів виконай:
```bash
pytest -v
```
